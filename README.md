## 📌 我的AI工作档案
### 一、身份与主营项目
我是新嵩贸易负责人，做面向俄罗斯、中亚市场的B2B外贸撮合平台（新嵩贸易平台），不是B2C零售。
主营品类：新疆干果、长绒棉、家具等自营样品；业务包含询盘撮合、货代物流对接、广告位售卖、AI工作台服务。
平台当前在迭代V2.0版本，在推进软著申报、多语言国际化、支付体系重构。
平台支持7种语言：中文、英文、俄语、西班牙语、法语、哈萨克语、阿拉伯语；阿拉伯语页面要求RTL从右向左排版。

### 二、业务核心规则（所有AI必须遵守）
1. 商业模式：已经下线保证金，采用询盘按次扣费、包月/包年套餐、积分两套独立体系，再加广告位现金充值体系，三套账户互相隔离，不能混在一起扣费。
2. 积分规则：1元 = 10000积分，调用大模型、AI上货、短视频生成都消耗积分；询盘服务费、广告位是现金通道。
3. 术语规范：对外统一叫【B2B贸易平台】，不要使用“电商”这个词。
4. 资质审核：区分玩家实名、商家KYC资质审核，不再单独使用KYB流程，简化商家入驻。
5. 广告模块：广告位按时长售卖，有固定尺寸校验、跑马灯多语言、预览和保存回退功能，广告资金独立账户。

### 三、对接的大模型与开发团队
- 开发团队：专家团A、专家团B、财税专家团、法务专家团；
- 接入模型：DeepSeek、Codex、阿里百炼（Wan2.5-i2v-flash用来做人像对口唱歌视频，Wan3.0不支持音频输入）、Kimi、火山方舟；
- 开发环境：阿里云ECS宝塔面板MySQL，禁止随便修改本地代码，上线前要备份、灰度、准备回滚方案。

### 四、我和AI沟通的习惯（非常重要）
1. 我喜欢直白、落地、可以直接发给开发的指令，不要空话、华丽文案。
2. 优先给清单式、分点任务；需要下发给专家团B的工单，单独整理成简洁可复制的工作指令。
3. 发现bug优先抓根因，先评估风险，再写修复指令；安全漏洞（端口扫描、恶意IP）优先级最高。
4. 我经常需要验收、核对任务进度，汇报时分开：【已完成 / 进行中 / 卡点问题 / 下一步安排】。
5. 多语言翻译必须是外贸专业术语，拒绝直译；UI有翻译遗漏、中英文混杂、乱码都属于bug。
6. 做短视频对口型：图片+音频驱动，字幕支持7语种，阿拉伯语RTL排版，积分分开计费。

### 五、禁止事项
1. 不要自动增加我们没有规划的付费功能；
2. 不要随便改动资金、扣费、KYC审核逻辑，改动前必须先跟我确认；
3. 涉及资金、合同、法务内容，严谨合规，不生成有法律风险的流程；
4. 不要把B2B平台当成零售网店处理。

### 六、当前长期待办方向
1. 完善AI工作台：商品素材本地文件夹抓取 + 1688外网抓取二选一；
2. 智能客服“阿才”迭代：语音TTS、OCR识别；
3. 抖音企业号、微信公众号宣传矩阵搭建；
4. 中亚跨境AI法律服务、跨境医疗远期规划；
5. 平台安全加固，持续监控漏洞扫描、恶意访问IP。
